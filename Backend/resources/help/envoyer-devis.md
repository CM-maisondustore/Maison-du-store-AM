## Étapes

1. Sur la fiche du devis validé, touchez **Préparer l’envoi du devis**.
2. Choisissez le **Canal** (**E-mail** ou **WhatsApp manuel**) puis le **Modèle**, et touchez **Charger le modèle**. Le message se remplit avec la civilité, le nom du client, le numéro et le montant.
3. Relisez l’**Objet** et le **Message** ; modifiez-les si besoin.
4. À côté du document joint, **Aperçu** ouvre le PDF tel que le client le recevra. Le **crayon (Mise en page)** ajuste la présentation de ce devis seulement, sans toucher au modèle commun.
5. Touchez **Enregistrer le brouillon**. La page du message s’ouvre.
6. Pour un e-mail : touchez **Envoyer depuis contact@maisondustoream.com**. Le PDF est joint automatiquement.
7. Pour WhatsApp : touchez **Ouvrir le message dans WhatsApp**, envoyez-le au client, puis revenez et touchez **Marquer comme partagé**.

![La préparation de l’envoi](capture:envoi-devis)

> **Bon à savoir.** Sur WhatsApp, un lien sécurisé vers le PDF est ajouté à la fin du message ; il reste valable 30 jours. Le client ouvre une page de téléchargement, et la page **Visiteurs** indique quand il a ouvert ou téléchargé le document.

## Mise en page propre à un devis

1. Touchez le **crayon** à côté du document.
2. Sélectionnez un bloc et modifiez-le : texte, intitulé, police, lignes affichées, séparations, tableau. **Aperçu PDF** montre le résultat.
3. Touchez **Enregistrer pour ce devis**. **Reprendre le modèle commun** annule ces réglages.

Ce réglage n’est plus possible une fois le devis accepté ou facturé.
