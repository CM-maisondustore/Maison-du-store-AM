## À quoi ça sert

Les rendez-vous sont les visites demandées par les clients sur le site (au showroom ou à domicile). Le bureau les confirme et vous les affecte.

![La liste des rendez-vous](capture:agent-rendez-vous)

## Étapes

1. Ouvrez l’onglet **RDV**. Les rendez-vous sont classés par jour.
2. Touchez un rendez-vous pour voir la **Demande du client** : nom, téléphone, adresse, type de projet.
3. L’état indique si le rendez-vous est **Confirmé** ou encore **À traiter**.

> **Bon à savoir.** Pour changer l’heure, l’agent ou annuler un rendez-vous, prévenez le bureau : ces modifications sont réservées au manager et à l’administrateur.
