## Lire les messages

1. Ouvrez **Messagerie**. Les messages non lus sont comptés dans le menu.
2. Touchez **Relever les e-mails** pour importer les derniers messages de contact@maisondustoream.com.
3. Sélectionnez un message pour le lire. Touchez **Répondre** pour préparer la réponse.

![La messagerie](capture:messagerie)

## Écrire un message

1. Touchez **Nouveau message** (e-mail) ou **Nouveau WhatsApp**.
2. Choisissez le **Modèle** et le **Dossier associé** (client, devis ou facture), puis **Charger le modèle**.
3. Relisez, puis **Enregistrer le brouillon**.
4. Envoyez : **Envoyer depuis contact@maisondustoream.com** pour un e-mail ; pour WhatsApp, **Ouvrir le message dans WhatsApp** puis **Marquer comme partagé**.

Un brouillon inutile se supprime avec **Annuler ce brouillon**.

> **Bon à savoir.** La messagerie affiche le texte seul, 20 messages par page. Les messages de plus de 1 Mo et les pièces jointes se consultent dans le webmail (**Ouvrir le webmail**). Pour une promotion, l’envoi exige un consentement enregistré dans le dossier du client.
