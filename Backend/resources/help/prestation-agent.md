## À quoi ça sert

Une prestation est une visite chez le client : pose, service après-vente ou devis sur place. Le bureau la planifie et vous l’affecte ; vous la suivez depuis votre téléphone.

![Une prestation ouverte sur téléphone](capture:agent-prestation)

## Étapes

1. Ouvrez **Prestations** (ou la carte de la prochaine intervention sur **Aujourd’hui**) et touchez la prestation.
2. En haut, **Appeler**, **Itinéraire** et **WhatsApp** contactent le client ou ouvrent le trajet. Lisez ensuite les **Consignes** : code du portail, matériel à prévoir, remarques du bureau.
3. Pour une pose, la rubrique **À poser** liste les ouvertures et les produits prévus au devis.
4. À votre arrivée, touchez **Démarrer l’intervention**. Le bureau voit que la prestation est **En cours**.
5. Avant de partir, remplissez **Compte rendu de l’intervention** : ce qui a été fait, les problèmes rencontrés, la suite à donner. Touchez **Enregistrer le compte rendu**.
6. Touchez **Terminer l’intervention**. Le compte rendu est obligatoire ; la date et l’heure de fin sont enregistrées.

> **Bon à savoir.** Une erreur ? Tant que la prestation n’est pas terminée, ouvrez **Revenir à l’état « Planifié »** puis **Enregistrer le suivi** pour annuler le démarrage. Le compte rendu est gardé sur le téléphone tant qu’il n’est pas enregistré. Le client ne reçoit aucun message quand vous démarrez ou terminez.

Pour un devis sur place, voyez [Faire un relevé sur place](guide:releve-sur-place).
